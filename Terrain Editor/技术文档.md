## 二、核心算法实现

### 2.1 地形生成算法

#### Perlin噪声地形生成

支持6种地形类型，每种类型有独立的噪声参数和生成逻辑：

```csharp
private void GenerateHills(float[,] heightMap, int width, int depth)
{
    // 预计算噪声图，避免重复计算
    float[,] noiseMap = new float[width, depth];
    for (int z = 0; z < depth; z++)
    {
        for (int x = 0; x < width; x++)
        {
            float noiseValue = Mathf.PerlinNoise(
                (x + offsetX) * frequency, 
                (z + offsetZ) * frequency);
            noiseMap[x, z] = Mathf.Clamp(noiseValue, 0.001f, 0.999f);
        }
    }

    // 3x3邻域平滑，消除单点异常
    for (int z = 0; z < depth; z++)
    {
        for (int x = 0; x < width; x++)
        {
            float smoothNoise = GetSmoothNoise(noiseMap, x, z, width, depth);
            heightMap[x, z] = Mathf.Pow(smoothNoise, smoothness) * amplitude;
        }
    }
}
```

#### 关键技术点

| 技术点 | 实现方式 | 作用 |
|-------|---------|------|
| 确定性生成 | `Random.InitState(seed)` | 相同种子生成相同地形 |
| 多层噪声叠加 | 八度频率+振幅衰减 | 增加地形复杂度 |
| 邻域平滑 | 3×3邻域平均 | 消除噪声异常值 |
| 边缘安全处理 | 边界Clamp | 避免数组越界 |

### 2.2 笔刷编辑算法

#### Smoothstep衰减算法

解决笔刷边缘生硬的核心算法：

```csharp
float falloff = 1 - (distance / brushRadius);
// Smoothstep三次多项式插值
falloff = falloff * falloff * (3 - 2 * falloff);
```

**效果对比**：
- 线性衰减：`falloff = 1 - (distance / radius)` → 边缘过渡生硬
- Smoothstep衰减：平滑的S形曲线 → 自然的过渡效果

#### 四种编辑模式实现

| 模式 | 核心算法 | 关键代码 |
|------|---------|---------|
| 升高/降低 | 基于强度和距离衰减 | `y += strength * falloff * deltaTime` |
| 粗糙化 | Perlin噪声扰动 | `y += noise * strength * falloff` |
| 平整 | 目标高度插值 | `y = Lerp(y, target, strength * falloff)` |
| 平滑 | 邻域平均 | `y = Lerp(y, avgHeight, strength * falloff)` |

#### 顶点邻域平均算法

```csharp
float GetNeighborAverage(int index, int x, int z)
{
    float sum = 0f;
    int count = 0;
    
    // 检查4邻域顶点
    if (x > 0) { sum += _vertices[index - 1].y; count++; }
    if (x < width) { sum += _vertices[index + 1].y; count++; }
    if (z > 0) { sum += _vertices[index - width - 1].y; count++; }
    if (z < depth) { sum += _vertices[index + width + 1].y; count++; }
    
    return count > 0 ? sum / count : _vertices[index].y;
}
```

### 2.3 相机控制算法

#### 高度自适应速度系统

```csharp
void AdjustSpeedBasedOnHeight()
{
    // 物理射线检测地面距离
    if (Physics.Raycast(transform.position, Vector3.down, out RaycastHit hit, 1000f))
    {
        float distanceToGround = hit.distance;
        // 高度越高速度越快：1x ~ 3x倍率
        float speedMultiplier = Mathf.Lerp(1f, 3f, distanceToGround / 100f);
        moveSpeed = baseMoveSpeed * speedMultiplier;
    }
}
```

**技术要点**：
- 射线检测间隔节流，避免每帧计算
- 线性插值实现平滑速度过渡
- 距离阈值防止极端值

## 三、关键技术难点

### 3.1 难点一：大数据量网格索引管理

**问题**：顶点数组尺寸为 `(width+1) × (depth+1)`，但高度图只有 `width × depth`，导致边缘顶点索引越界。

**错误代码**：
```csharp
// ❌ 错误的索引公式
int index = z * config.width + x;
heightMap[x, z] // 当x或z等于width/depth时越界
```

**正确方案**：
```csharp
// ✅ 正确的索引公式
int index = z * (width + 1) + x;

// 边缘安全处理
float height;
if (x < width && z < depth)
{
    height = heightMap[x, z];           // 中间区域
}
else if (x == width)
{
    height = heightMap[x - 1, z];       // 右边缘
}
else if (z == depth)
{
    height = heightMap[x, z - 1];       // 下边缘
}
else
{
    height = heightMap[x - 1, z - 1];   // 右下角
}
```

**约束条件**：
- Unity单Mesh顶点数上限约65,000
- 256×256地形顶点数65,537，接近极限
- 超大尺寸需要分块地形方案

### 3.2 难点二：地形生成与编辑的数据同步

**问题**：地形生成后，`TerrainEditor`持有的顶点数组副本未更新，导致笔刷编辑基于旧数据。

**解决方案**：
```csharp
public void Generate()
{
    // 1. 创建新Mesh
    Mesh mesh = CreateTerrainMesh();
    meshFilter.sharedMesh = mesh;
    
    // 2. 关键：同步顶点数据到编辑器
    terrainBrush.SyncVerticesFromMesh();
    
    // 3. 触发事件通知
    OnTerrainGenerated?.Invoke();
}

public void SyncVerticesFromMesh()
{
    _vertices = mesh.vertices;
    _smoothedVertices = (Vector3[])_vertices.Clone();
    terrainState = TerrainState.Editable;
}
```

**状态管理**：
```
NotGenerated → Generating → Editable
     ↑                            │
     └──── ClearTerrain ←─────────┘
```

### 3.3 难点三：自定义Inspector布局管理

**问题**：在UI布局中间调用`EditorUtility`对话框会打断布局配对，导致`EndLayoutGroup`错误。

**错误代码**：
```csharp
void DrawDataIO()
{
    EditorGUILayout.BeginVertical("Box");
    
    if (GUILayout.Button("导出"))
    {
        // ❌ 对话框打断布局
        string path = EditorUtility.SaveFilePanel(...);
    }
    
    EditorGUILayout.EndVertical();
}
```

**正确方案**：
```csharp
private bool _showExportDialog = false;

void OnInspectorGUI()
{
    // 1. 先绘制所有UI布局
    DrawDataIO();  // 只设置标志，不打开对话框
    
    // 2. 应用修改
    serializedObject.ApplyModifiedProperties();
    
    // 3. 布局完成后处理对话框
    if (_showExportDialog)
    {
        _showExportDialog = false;
        string path = EditorUtility.SaveFilePanel(...);
        // 处理导出逻辑
    }
}

void DrawDataIO()
{
    EditorGUILayout.BeginVertical("Box");
    
    if (GUILayout.Button("导出"))
    {
        _showExportDialog = true;  // ✅ 只设置标志
    }
    
    EditorGUILayout.EndVertical();
}
```

### 3.4 难点四：多模式参数独立管理

**问题**：所有编辑模式共享同一个`brushStrength`参数，修改一个模式会影响所有模式。

**解决方案**：
```csharp
[Serializable]
public class BrushConfig
{
    public float raiseLowerStrength = 1f;   // 升高/降低独立参数
    public float roughenAmount = 0.5f;     // 粗糙化独立参数
    public float flattenStrength = 1f;     // 平整独立参数
    public float smoothStrength = 1f;      // 平滑独立参数
}

public float GetCurrentModeStrength(EditMode mode)
{
    return mode switch
    {
        EditMode.RaiseLower => brush.raiseLowerStrength,
        EditMode.Roughen => brush.roughenAmount,
        EditMode.Flatten => brush.flattenStrength,
        EditMode.Smooth => brush.smoothStrength,
        _ => 1f
    };
}
```

## 四、性能优化体系

### 4.1 渲染性能优化

| 优化项 | 实现方法 | 性能收益 |
|-------|---------|---------|
| 网格更新节流 | `meshUpdateThrottle = 0.033f` | 限制更新频率约30fps |

| 顶点插值 | 平滑顶点数据副本 | 避免高频重新计算 |

**网格更新节流机制**：
```csharp
void LateUpdate()
{
    if (_needsMeshUpdate && Time.time - _lastUpdateTime > meshUpdateThrottle)
    {
        UpdateMesh();
        _lastUpdateTime = Time.time;
        _needsMeshUpdate = false;
    }
}
```

**笔刷计算优化**：
```csharp
void ModifyTerrain(Vector3 hitPoint)

        }
    }
}
```

### 4.3 内存管理优化

| 优化项 | 实现方法 | 说明 |

### 5.3 事件驱动架构

```csharp
// 静态事件中心
public static class TerrainEvents
{
    public static event Action OnTerrainGenerated;
    public static event Action<string> OnExportSuccess;
    
    public static void InvokeTerrainGenerated()
    {
        OnTerrainGenerated?.Invoke();  // 空引用安全
    }
}

// 订阅示例
void SubscribeToEvents()
{
    terrainGenerator.OnTerrainGenerated += () => 
        TerrainEvents.InvokeTerrainGenerated();
}
```
